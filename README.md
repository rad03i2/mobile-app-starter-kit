# مَن سيربح المليون؟ — لعبة معلومات عربية

لعبة Android عربية تعليمية غير رسمية، مستوحاة من أسلوب مسابقات المعلومات العامة. تحتوي على رحلة كاملة من 15 سؤالاً حتى جائزة المليون، بواجهة داكنة ذهبية تعمل من اليمين إلى اليسار.

> هذا مشروع تجريبي مستقل وغير تابع للبرنامج التلفزيوني أو مالكي علامته التجارية. لا يستخدم شعارات أو أصواتاً أو مواد أصلية للبرنامج.

## المزايا

- 15 سؤالاً متدرجاً في الثقافة العامة والعلوم والتاريخ واللغة.
- أربعة خيارات لكل سؤال مع توضيح الإجابة بعد الاختيار.
- سلم جوائز من `$100` إلى `$1,000,000`.
- محطتا أمان عند `$1,000` و`$32,000`.
- مؤقت 30 ثانية لكل سؤال ويتحول إلى الأحمر في الثواني الأخيرة.
- ثلاث وسائل مساعدة تستخدم مرة واحدة:
  - `50:50` لحذف إجابتين خاطئتين.
  - الاتصال بصديق للحصول على اقتراح.
  - تصويت الجمهور مع رسم نصي للنسب.
- خيار الانسحاب والاحتفاظ بالجائزة المحققة.
- شاشة بداية، شاشة لعب، شاشة نتيجة، وإعادة اللعب.
- حفظ تقدم الجولة عند دوران الشاشة وحفظ أفضل جائزة على الجهاز.
- تصميم عربي RTL وأزرار ذات أوصاف مساعدة لقارئات الشاشة.
- لا إنترنت، لا حسابات، لا إعلانات، لا تحليلات، ولا صلاحيات حساسة.

## لقطات تجربة الواجهة

التصميم يستخدم خلفية كحلية، ألواحاً زرقاء داكنة، وحدوداً ذهبية. تتحول الإجابة الصحيحة إلى الأخضر والخاطئة إلى الأحمر، ويعرض التطبيق شرحاً مختصراً قبل الانتقال للسؤال التالي.

## المتطلبات التقنية

- Kotlin
- Android SDK 35
- Android 7.0 أو أحدث (API 24+)
- Java 17
- Gradle 8.9
- لا توجد مكتبات تشغيل خارجية

## التشغيل في Android Studio

1. انسخ المستودع أو نزّله بصيغة ZIP.
2. افتح مجلد المشروع في Android Studio.
3. ثبّت Android SDK 35 واختر JDK 17 عند الطلب.
4. انتظر اكتمال Gradle Sync.
5. شغّل التطبيق على محاكي أو هاتف Android.

## إنشاء APK

```bash
gradle assembleDebug
```

الملف الناتج:

```text
app/build/outputs/apk/debug/app-debug.apk
```

يبني GitHub Actions نسخة APK تلقائياً بعد كل تحديث لفرع `main`. افتح آخر تشغيل ناجح من تبويب **Actions** ثم نزّل `millionaire-arabic-debug` من قسم **Artifacts**.

## بنية المشروع

```text
app/src/main/java/dev/rad03i2/simplequiz/MainActivity.kt  الشاشات ومنطق اللعبة والمؤقت
app/src/main/res/values/strings.xml                      نصوص الواجهة العربية
app/src/main/res/values/colors.xml                       نظام الألوان
app/src/main/res/drawable/ic_quiz_logo.xml               أيقونة Vector أصلية
app/src/main/AndroidManifest.xml                         تعريف التطبيق
COPILOT_PROMPT.md                                        مواصفات التطوير المقترحة لـ Copilot
.github/workflows/android.yml                            بناء APK تلقائياً
```

## تعديل الأسئلة والجوائز

- الأسئلة موجودة في قائمة `questions` داخل `MainActivity.kt`.
- يجب أن يحتوي كل سؤال على تصنيف، نص، أربعة خيارات، رقم الإجابة الصحيحة، وشرح.
- قيم سلم الجوائز موجودة في قائمة `prizes` في الملف نفسه.

## الخصوصية

يعمل التطبيق محلياً بالكامل. التخزين الوحيد هو أفضل جائزة عبر `SharedPreferences` على جهاز المستخدم.
